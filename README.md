# ShiftReport

Приложение для сдачи смен, инвентаризации, истории отчётов и расчёта зарплаты.

Стек: Expo/React Native/Web, SmartShell SDK, Supabase PostgreSQL, Netlify и EAS.

## Быстрый старт

```bash
cp .env.example .env.local
npm ci
npm run web
```

Для проверки перед push:

```bash
npm run ci
```

Полная схема окружений, миграции Supabase, Netlify, EAS и CI описаны в [docs/INFRASTRUCTURE.md](docs/INFRASTRUCTURE.md).
