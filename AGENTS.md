# AGENTS.md

## Что это за проект

ShiftReport — сервис для автоматизации отчётности по рабочим сменам. Он помогает сотрудникам сдавать и принимать смены, контролировать смены и рассчитывать заработную плату.

## Текущая цель

- Главная цель: упростить сдачу и приём смен сотрудниками, контроль смен и расчёт заработной платы.
- Сейчас работаем над: дизайном проекта.
- Готово считается, когда: обновлённый дизайн удобен для сдачи и приёма смен, контроля истории и расчёта зарплаты, а API-интеграция продолжает работать.

## Стек

- ОС: Windows
- Технологии: React/TypeScript, Expo, React Native Web, CSS, API.
- Как запустить локально: выполнить `npm install`, затем `npm run web` и открыть адрес, который покажет Expo.

## Правила работы

- Перед изменениями сначала кратко объясни план.
- Не переписывай весь проект без необходимости.
- Не удаляй файлы, если я явно не попросил.
- После изменений скажи, какие файлы изменены и как проверить результат.
- Если задача неясна — задай 1-3 конкретных вопроса.

## Запреты и безопасность

- Не записывай API-ключи, пароли, токены в AGENTS.md, wiki/ или sessions/.
- Секреты — только в .env (и .env должен быть в .gitignore).
- Не отправляй приватные данные во внешние сервисы без моего разрешения.
- Нельзя ломать приём и сдачу смен, контроль смен, историю и API-интеграцию.

## Память проекта

- Журнал работ: wiki/log.md
- Решения: wiki/decisions.md
- Последний handoff: самый свежий файл в sessions/

## Ритуал handoff

В конце каждой сессии:

1. Обнови файл sessions/YYYY-MM-DD-topic-handoff.md.
2. Добавь одну короткую запись в wiki/log.md.
3. Укажи следующий конкретный шаг.
